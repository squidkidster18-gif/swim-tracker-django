# Swim Instructor Tracker (Django App)

## Overview
I rebuilt my Streamlit swim instructor app into a Django CRUD app. It helps track student progress, manage lesson plans, and plan a 16-week progression.

## Features
- Student + level management
- Skill checklist with auto level-up
- Lesson plans
- 16-week planner (editable)

## Tech Stack
- Python
- Django
- SQLite

## How to Run
python manage.py runserver
